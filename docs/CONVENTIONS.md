# Conventions

All of them match Figure 1 and Figure 6 of the article.

| Item | Convention |
|---|---|
| Units | μ = 1, ζV^S = 1, \|Q\| = 1. Hence `A_perp` is A_⊥/h and `B_perp` is B_⊥/h, both in units of 1/Q |
| Frame | n̂ = ẑ, Q̂ = (cos θ, sin θ, 0), e_⊥ = Q̂ × n̂ |
| Spinners | r₁ = −Q/2 rotates counterclockwise as seen from the tip of n̂, r₂ = +Q/2 rotates clockwise, center r_c = 0 |
| Eq. (2) | μ∇²v = ∇p + ΣF, where F is the force that the fluid exerts on the spinners. The force acting on the fluid is −F (`FLUID_SIGN = -1`) |
| Force points (Fig. 1) | A = Q/2 + R e_⊥, B = Q/2 − R e_⊥, C = −Q/2 + R e_⊥, D = −Q/2 − R e_⊥, signs s_A = s_D = +1, s_B = s_C = −1 |
| Eq. (4) | V_conf = [v(A) − v(B)] − [v(C) − v(D)] = Σ s_P v(P) |
| Scalar T | T = V_conf · e_⊥ (column `T`) |
| Eq. (5) | A_⊥ = (μh/ζV^S)(Q̂ × V_conf)·(â₁ × Q̂) = −(μh/ζV^S) T sin θ. The factor is sin θ, not sign(θ) |
| Stability | A_⊥ < 0 (blue) pushes Q towards a⁽¹⁾. In HEX: stable for 0 < \|θ\| < π/6, because T ≃ c₆ · 126 K(h) sin 6θ with c₆ > 0 |
| Eq. (3) | [V^f]_⊥ = (ζV^S/μ)(B_⊥/h) e_⊥, where V^f is the fluid velocity averaged over the reference sub-volume |
| Sub-volume | ball of radius r_f = √2h/4 ≈ 0.354h centered on the pair, the same in every lattice and geometry. It is the largest ball that does not overlap with those of the nearest neighbors in any of the four lattices (half the nearest-neighbor distance of the FCL). It contains the four forces of the pair and none of the neighbors as long as Q/h ≤ 0.25 |
| BCL and FCL lattices | rotated so that a⁽³⁾ lies along ẑ. θ is measured from the projection of a⁽¹⁾ onto the plane perpendicular to a⁽³⁾ |
| Geometries | `bulk3d`: 3D lattice in a 3D fluid (Ewald sums, velocities relative to the mean fluid velocity). `monolayer`: 2D lattice {c₁a⁽¹⁾ + c₂a⁽²⁾} in an unbounded 3D fluid at rest far away (extrapolated direct sums) |

## The average over the sub-volume

The average over a whole unit cell vanishes for k ≠ 0, and the k = 0 mode is undetermined for force-free
swimmers, so V^f is defined as a local average. It is evaluated without Fourier sums:

V^f = ⟨v_pair⟩_ball + [v_per(0) − v_pair(0)] + (a²/10μ) ∇p_img(0),  a = r_f

In the CSV files: `B_perp = −QR/(10π r_f³) + B_img + r_f² gradp_img/10`. The columns `B_img` and `gradp_img`
allow B_⊥ to be recomputed for any other radius without repeating the sums.

- ⟨v_pair⟩_ball is the exact average of the flow generated by the pair itself:
  (1/8πμa³) Σ_P [(2a² − 4|P|²/5) F_P + (2/5) P (P·F_P)] = −ζV^S Q R e_⊥/(10πμa³).
- The flow of the images is biharmonic inside the ball, so its average is u(0) + a²Δu(0)/10
  (mean-value theorem), with Δu = ∇p/μ.
- ∇p_img(0) is the sum over the images of the pair (it decays as d⁻⁵ and converges absolutely).

`tests/test_average.py` compares this evaluation with an independent Fourier sum with the form factor of the
ball, 3(sin x − x cos x)/x³ with x = 2π|k|a. The relative agreement is better than 2·10⁻³ in every lattice and
geometry.

### Why a common radius

The self term of the pair, −ζV^S QR/(10πμ r_f³), dominates B_⊥. With a lattice-dependent radius such as
r_f = d_nn/2, r_f³ would change by a factor of 2.8 between the SCL and the FCL, and the comparison between lattices
would mostly reflect the size of the ball. With the same radius in every lattice the self term is the same at equal
Q/h, and the differences come only from the lattice. A_⊥ does not depend on r_f.

## Physical caveat (also discussed in the article)

By inversion symmetry, v(r₂) = v(r₁) in every Bravais lattice (`test_centres_are_advected_with_the_same_velocity`).
V_conf measures the velocity difference across the diameter 2R, and [V_conf]_⊥ is used as a measure of the
orienting hydrodynamic torque.
